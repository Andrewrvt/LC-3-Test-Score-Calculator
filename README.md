# LC-3-Test-Score-Calculator

Authors: Manuel Nunez, Eric Espinoza

This program displays the minimum, maximum and average grade of 5 test scores and display the letter grade associated with the test scores.

# Step by step Operation 

The user is prompted to input 5 scores between 0-100.

The 5 scores are compared to min and max values to determine which one is which.

The average of the 5 values is calculated using the required mathematical operations and is then displayed with the corresponding letter grade as seen below. 

A: 100-90  B: 89-80  C: 79-70  D: 69-60  F: 59-0
